## 🚀 Overview

This repository hosts the corporate website for **Uptech LLC**, focusing on our pivot towards **AI Augmented Digital Transformation**. The site is designed to showcase our capabilities in leveraging Generative AI and LLMs to revolutionize business operations and software development.

## ✨ Features

- **AI-First Identity:** Content tailored to highlight AI-driven methodologies.
- **Modern & Professional:** Clean, responsive design with a "Dark Tech" aesthetic.
- **Performance:** Lightweight, vanilla implementation for maximum speed.
- **Responsive:** Fully optimized for mobile, tablet, and desktop.

## 🛠 Technologies Used

- **HTML5:** Semantic structure.
- **CSS3:** Advanced styling, gradients, animations, and flexbox/grid layouts.
- **JavaScript:** Vanilla JS for smooth scrolling and intersection observers.
- **Design Philosophy:** Minimalist, content-first, and performance-oriented.
